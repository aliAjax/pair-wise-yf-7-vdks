# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

## 补字对账

工坊缺字托外协铸字房补，回货常和缺字对不上，因此做了补字对账：

- **按版面缺字汇总**：当前版面与每份已保存草稿的缺字按（字、风格）汇总成需求，显示缺多少枚、涉及几个版面。
- **同款字接着跟**：生成补字单时，同款字已有未结单就更新它的未结数量，不重复开单。
- **分批发回逐批核销**：登记回货时填回单号与每行（字、风格、数量），核销到对应补字单；到账的字模数量自动加进字模库。
- **同一份回单只算一次**：回单号去重，重复录入会被拒绝，不重复加库存、不重复核销。
- **多发存成抵用**：到货超出未结数量的部分转成抵用余额，自动抵扣同款字的未来需求。
- **对不上先挂着等裁**：没有未结单的回货（错发/多送）先挂账，可转抵用或标记错发销账。
- **缺字草稿重算 + 解锁**：补字到账后草稿缺口重算，缺口清掉才解锁（导出按钮在锁定时禁用并提示）。
- **字模数量更新 → 核销结果重算**：在字模库用步进器改数量后，需求、补字单未结数量、缺口、抵用全部跟着重算。
- **写入失败恢复上一份账**：每次写入前备份，写入失败自动回滚到上一份账；也可点「恢复上一份账」手动回滚。
- **关掉再开读回**：所有数据存 localStorage，关闭后重开自动读回。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
