# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出 PNG 预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。数据存于浏览器 localStorage，关掉再开自动读回。

## 补字账房

顶部「补字账房」页签负责外协铸字的对账，所有账目由源数据实时派生：

- **缺字汇总**：按版面落字，以「字 + 风格」归并缺口、在库、抵用、在途与待托铸枚数。
- **托铸补字单**：一键把缺口送外协。同款字已有未结补字单就把增量追加到原单同一行，不另开新单；抵用余额先冲抵。
- **分批核销**：铸字房分批发回，按回单号逐张登记、逐行核销，可跨行跨单分摊；已交数量达订单枚数自动结清。同一回单号登记两次只核销一次（幂等，重复贴单会被拒绝）。
- **溢发抵用**：超出未结单的多交部分不进常库，存为该款字的抵用余额，下次托铸优先冲抵。
- **挂账待裁**：回货若与未结单、本坊字模都对不上，先挂起不动账；人工裁决「收入抵用」或「退回铸字房」。页签上的红点表示有待裁挂账。
- **草稿解锁**：带缺字保存的草稿自动锁定、不可载入；补字到账使字模数量更新后，缺口与核销结果整体重算，缺口清零才解锁。
- **可靠落账**：每次写入先备份上一份主账再落新账；写入失败自动恢复上一份账，主账损坏时回退备份。

## 测试

纯账务逻辑可用 Node 直接跑冒烟测试（无需依赖）：

```bash
node test/ledger.test.js
```

覆盖缺字汇总、跟单追加、分批核销、回单幂等、溢发抵用、挂账裁决、草稿锁定/解锁、数量联动重算、写入失败回滚与持久化读回。
